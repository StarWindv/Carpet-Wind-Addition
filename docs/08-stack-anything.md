# 08 物品堆叠上限

## 用途

修改指定物品的堆叠上限，用于自定义堆叠或测试。

## 规则

```text
/carpet StackAnything true
/carpet MaxStackAnythingSize <正整数>
```

`MaxStackAnythingSize` 默认 `64`，只限制 `/stack` 可设置的范围，不影响已经保存的堆叠上限或其它堆叠行为。

## 用法

```text
/stack <物品 ID> <1-当前上限>
```

- `<物品 ID>`：支持带命名空间（例如 `create:copper_sheet`）和不带命名空间（例如 `copper_sheet`）。完整 ID 不存在时，会按路径在所有已注册命名空间中查找；多个匹配会提示使用命名空间。
- 设置只按物品名称匹配，不区分 NBT/组件。
- 原版 99 的硬堆叠上限已移除，实际堆叠数量跟随每个物品的设置（例如可以设置到 999）。
- 有耐久的物品堆叠后使用时，会先拆成 1 个正在使用的物品，其余放入背包；背包放不下时掉落在玩家附近，只有正在使用的那个消耗耐久。
- 调低某个物品的堆叠上限时，已经存在的超限堆叠不会自动拆分。
- 自定义堆叠的岩浆桶在熔炉/高炉/烟熏炉燃料槽中最多保留 1 个，多余的会掉落在炉子旁。

需要权限等级 2；单人存档/局域网主机不受此限制。客机可通过 `/allow stack` 放行，详见 [权限控制器](01-permissions.md)。
