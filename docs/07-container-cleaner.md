# 07 容器清理

## 用途

清理大型机器中因掉刻等原因混入其它组件的填充物。

## 规则

```text
/carpet ContainerCleaner true
```

## 用法

```text
/cc <起点> <终点> <容器方块> <物品> self
/cc <起点> <终点> <容器方块> <物品> discard
/cc <起点> <终点> <容器方块> <物品> to <起点> <终点>
```

- `<起点>`、`<终点>`：方块坐标，支持 `~` 等相对坐标。
- `<容器方块>`：方块 ID，`dropper` 和 `minecraft:dropper` 两种写法均可；命令会先检查它是否为容器。
- `<物品>`：物品 ID，同样支持短名称和带命名空间的写法。
- 只清理指定类型容器中的指定物品。
- 接收方式：
  - `self`：放入玩家背包。
  - `discard`：直接丢弃。
  - `to <起点> <终点>`：放入选区内的容器，支持箱子、木桶、放置的潜影盒等；正在被清理的容器和熔炉类容器会被跳过。
- 接收方放不下的物品会继续留在原容器槽位中，并给出提示。

需要权限等级 2；单人存档/局域网主机不受此限制。客机可通过 `/allow cc` 放行，详见 [权限控制器](01-permissions.md)。
