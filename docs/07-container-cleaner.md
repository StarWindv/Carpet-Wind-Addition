# 07 容器清理

## 用途

清理指定容器中的指定物品。

## 规则

```text
/carpet ContainerCleaner true
```

## 用法

```text
/cc <起点> <终点> <容器方块> <物品> self
/cc <起点> <终点> <容器方块> <物品> discard
/cc <起点> <终点> <容器方块> <物品> to <起点> <终点>
```

- 坐标支持 `~` 等相对坐标。
- 容器方块和物品 ID 支持短名称和带命名空间的写法。
- `self` 放入玩家背包，`discard` 丢弃，`to` 放入选区内的容器。
- 接收容器不包括正在清理的容器和熔炉类容器；放不下的物品留在原槽位。
