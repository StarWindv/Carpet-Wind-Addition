# 06 熔炉清理

## 用途

清理大型熔炉组中误投入的不可烧炼物品或不可作为燃料的物品，避免阻塞生产。

## 规则

```text
/carpet FurnacesCleaner true
```

## 用法

```text
/furnace <起点> <终点> self
/furnace <起点> <终点> discard
/furnace <起点> <终点> to <起点> <终点>
```

- `<起点>`、`<终点>`：方块坐标，支持 `~` 等相对坐标。
- 清理选区内的熔炉、高炉和烟熏炉：
  - 输入槽中无法在当前炉子烧炼的物品。
  - 燃料槽中不能作为燃料的物品。
  - 输出槽不会被清理。
- 接收方式：
  - `self`：放入玩家背包。
  - `discard`：直接丢弃。
  - `to <起点> <终点>`：放入选区内的容器，支持箱子、木桶、放置的潜影盒等；该区域内的熔炉不会作为接收容器。
- 接收方放不下的物品会继续留在熔炉中，并给出提示。

需要权限等级 2；单人存档/局域网主机不受此限制。客机可通过 `/allow furnace` 放行，详见 [权限控制器](01-permissions.md)。
